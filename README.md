# IB3 Self Driving Bycicle 2026-2027

This project aims to create a self driving and balancing bicycle.  
The assignment was given for the students of the KU Leuven Campus Gent (2026-2027).  
Here we built further on a [previous project](https://github.com/kayensmet/Self-driving-bicycle-2025-2026).  

To get started, we recommend to take a look at our [documentation](https://zelf-lijdende-fiets.github.io/IB3-Self-Driving-Bicycle-2627/index.html)
